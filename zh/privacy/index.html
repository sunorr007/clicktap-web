隐私政策

2026-09-14

生效日期：2026-09-14 · 最近更新：2026-09-14

本政策说明 clicktap 与本站收集哪些信息、为什么收集，以及你可以怎么做。它同时覆盖clicktap Android 应用（下称本应用）与本站（含公开的任务分享区，下称本站）。 两者均由 北京烽鸿科技有限责任公司 提供。

一、我们收集的信息

1.1 在本应用中

本应用没有账号体系，也不会上传你的数据。没有统计 SDK、没有广告 SDK、没有崩溃上报 SDK。

  • 你录制的内容留在设备上。任务、动作列表、循环结构、自动启动设置、执行日志、 导入的订阅规则与导出的备份，全部存放在本应用的私有目录中。
  • 无障碍信息是"读取"，不是"上传"。为了执行你录制的动作，本应用会读取目标 应用的无障碍节点信息——控件文本、控件标识、内容描述与坐标——用于在当时找到正确的控件， 不会发送到任何地方。本应用保存的是任务之后继续工作需要的内容：你为每个动作选定的 定位方式（控件 ID、文本或屏幕位置）。
  • 截图。当某一步使用文字识别时，本应用会向 Android 请求截图，识别你框选 区域内的文字。截图仅在该步骤的内存中处理，不会存入相册，也不会上传。
  • 通知文本。只有当你启用「消息触发」时，本应用才会读取你所选应用的通知 标题与正文，用于比对关键词。
  • 已安装应用列表。本应用会列出已安装应用供你选择目标；该列表只在设备上 读取，不会写进你的备份文件。

1.2 在本站

本站只收集运行分享功能所必需的信息：

  • 登录时的 GitHub 身份。我们会获得你的 GitHub 用户 ID、登录名、显示名与 头像地址并保存，用于标明内容作者。我们只申请 read:user 权限，无法读取你的 仓库，也永远不会拿到你的 GitHub 密码。
  • 你主动发布的内容。发布任务包时，我们会保存文件本身、你填写的标题与说明、 可选的封面图，以及从文件中解析出的技术信息（任务名、步骤数、是否含自动启动触发、录制 分辨率、涉及的目标应用包名）。已发布的内容对所有人可见。
  • 你提交的举报。保存举报内容、你的账号与理由。
  • 下载计数。统计已发布内容的下载次数。计数是汇总值，不与具体下载者关联。
  • 没有跟踪 Cookie。本站不设置广告或统计 Cookie。浏览器本地存储只用于一件事： 记住你的语言选择。登录状态必然会在浏览器中保存会话令牌。

二、我们如何使用信息

  • 运行与展示分享区，并标明内容作者。
  • 让他人下载你主动发布的任务包。
  • 处理举报，移除违规内容。
  • 维持服务运转、排查故障、防止滥用。

我们不出售你的信息，不将其用于广告或用户画像，也不会用你的操作数据训练机器学习模型。

三、本应用申请的权限

  • 无障碍服务——必需。这是本应用执行点击与手势、并读取所需控件的基础； 未开启则回放无法工作。
  • 悬浮窗（显示在其他应用上层）——必需。用于录制悬浮条与录制时的捕获层。
  • 通知使用权——可选。仅供「消息触发」读取你指定应用的通知文本。
  • 闹钟和提醒、全屏通知——可选。用于让定时执行更准时，以及锁屏提醒能亮屏。
  • 忽略电池优化——可选。减少 Android 在后台中断执行的可能。
  • 网络——仅在你选择通过 URL 导入规则时使用。

每一项权限在申请前都会在应用内说明用途，你也可以随时在 Android 设置里收回。

四、存储、安全与保留

  • 应用数据存放在本应用的私有目录中，卸载应用即删除。
  • 本站数据存放在我们的托管服务商处（见第五条）。任务包保存在私有存储中，通过短时效的 签名链接下发；内容一旦被移除，该链接随即失效。
  • 已发布内容会一直保留，直到你删除或我们移除。删除会将其从本站移除并停止新的下载； 但已经被他人下载的副本，我们无法追回。
  • 我们全程使用 HTTPS，并把数据库访问限制在每项操作所需的最小范围。没有绝对安全的系统， 我们无法保证绝对安全。

五、第三方服务

以下是我们涉及的全部第三方。我们不使用广告或跟踪服务。

  • Google ML Kit 文字识别（本应用，可选功能）。当某一步使用文字识别时， 本应用使用 Google ML Kit 的端上文字识别模型（拉丁与中文两种）。模型随应用一起打包， 识别在你的设备上完成，文字与图像不会发送给 Google。ML Kit 是 Google 的产品，适用 Google 的条款。若你从不使用文字识别步骤，则该组件不会被使用。说明：本政策此前的版本称本应用"未集成任何收集用户信息的第三方 SDK"。该表述写于文字 识别功能上线之前，之后就与实际不符。此处予以更正。
  • Supabase（本站）。提供本站的登录、数据库与文件存储。项目所在区域见你的 Supabase 项目设置。Supabase 作为受托方代表我们处理这些数据。
  • GitHub（本站登录与源码托管）。用于登录，以及托管本应用的源代码与发布 包。你的 GitHub 账号适用 GitHub 自身的隐私政策。

六、发布意味着什么

这一条比本页其他内容都更重要，因此直说。

任务包是你录制内容的忠实副本。发布之后，它会原样存储与公开，不会剥离任何字段。 视录制方式不同，公开的任务包可能包含：

  • 任务名，以及你在单个步骤上手打的备注；
  • 各动作要查找的屏幕文本、控件描述与控件 ID——其中可能包含你屏幕上出现过的联系人名、 消息片段、价格或账号标识；
  • 消息触发要等待的通知关键词；
  • 任务涉及的所有应用的包名与应用名；
  • 目标应用内部的界面类名；
  • 你录制时的屏幕分辨率，以及时间与标识类数值；
  • 以及，如果任务使用了自定义提醒铃音，铃音文件本身会被原样复制，连同原始 文件名一起公开。

发布前，本站会把从你的任务包里解析到的内容逐项列出，并展开显示真实取值。 请务必看完。只发布你愿意交给陌生人的内容，也不要发布他人的个人信息。你还可以关闭 「包含内嵌的提醒铃音」，关闭后会在发布前移除该铃音文件及其文件名引用。

一旦任务包被他人下载，我们无法从对方手中收回。

七、你的选择与权利

  • 随时删除已发布内容。可在内容页面或账号区域的入口操作。删除后对所有人 移除，并停止新的下载。
  • 随时退出登录；会话令牌会从浏览器中清除。
  • 查询、更正或删除我们持有的与你账号相关的数据（GitHub 身份及你发布的 内容），请发邮件至 support@company.example.com，我们将在 30 天内答复。
  • 如果你所在司法辖区赋予你特定的数据保护权利，这些权利适用于上述数据，你也可以向当地 监管机构投诉。

八、未成年人

本应用与本站不面向 13 周岁以下（或你所在辖区规定的最低年龄）的儿童，我们也不会主动收集 其个人信息。如你认为有儿童发布了内容，请联系我们，我们会将其移除。

九、跨境传输

我们的服务商可能在你所在国家/地区之外处理数据。在适用法律要求时，我们依赖服务商为跨境 传输提供的合规保障。如果你发布了涉及他人的个人信息，你需要自行确保具备合法依据。

十、政策变更

随着本应用与本站的变化，我们可能更新本政策。上方的生效日期始终反映当前版本；重大变更会 在应用内或本站说明。本政策的上一版本仅覆盖本应用，并声称未集成任何第三方 SDK，现已被 本文取代。
