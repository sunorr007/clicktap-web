01

上手

从安装到第一次回放

  1. 01

    开两个权限

    这一步的目标：让 clicktap 拿到「能替你点击」和「能浮在别的应用上」两把钥匙。

    1. 安装 clicktap（Android 10 及以上；文字识别需要 Android 11+）。首次启动阅读并同意隐私政策。
    2. 首页「运行状态」里点「无障碍服务」这一行，在系统列表里找到 「clicktap 无障碍服务」并开启——它才是真正执行点击与滑动的能力。
    3. 再点「悬浮窗权限」，允许「显示在其他应用上层」——录制悬浮条靠它显示。
    4. 权限只能在系统设置里开关，App 内的开关只是入口；返回后状态自动刷新。三个可选权限用到再开：通知使用权（消息触发）、闹钟和提醒（定时更准）、忽略电池优化（后台不被限制）。

    完成标志： 回到 clicktap，「运行状态」里两行都变成绿色「已开启」，「开始录制」按钮亮起。

  2. 02

    录一段，放一遍

    这一步的目标：把一段真实操作变成任务，再亲手把它回放一遍。

    录制

    1. 首页点大按钮「开始录制」，给任务起名，比如「每日签到」。名字只是标签，不影响回放。
    2. 屏幕边缘出现悬浮条，此时还在待命；点条上的「开始录制」才真正开始。
    3. 像平时一样操作目标 App：每一下点击、长按、滑动都被记录，同时正常执行。两步之间的真实停顿会被记为后一步的「执行前等待」（最长 60 秒）。
    4. 要按返回或回桌面？用悬浮条上的「返回」「主页」按钮——系统导航键录不到。
    5. 「暂停」可以先不管；点「结束」就保存任务。录制中悬浮条变红，暂停时变橙。

    回放

    1. 首页点这张任务卡进入「任务详情」，点底部「运行回放」。
    2. 回放先挂起，真正的启动在回放悬浮条上按「开始回放」。
    3. 播放中可「暂停」「继续」，或「单步」——一次只走一个动作，逐个检查定位准不准。

    完成标志： 任务详情里能看到录下的动作列表，回放从头到尾走完一遍。

  3. 03

    多指手势

    这一步的目标：双指缩放、多指操作也能录进去。

    录制中用两根以上手指同时按住屏幕画出手势，全部抬手即录完一条，最多可录三指。 手势轨迹由录制生成，不能逐指手改——要改就重录。如果手势需要一块干净的屏幕，可以在白屏上录制。

    完成标志：录完一条手势动作，回放时多指轨迹原样出现。

  4. 04

    让每个动作找到它的目标

    这一步的目标：弄懂定位方式——它决定任务几周后还灵不灵。

    1. 任务详情里点任意动作，进入「动作编辑」。
    2. 控件查找（最可靠）：按控件 ID、可见文本或描述匹配，多条件可「与 / 或」组合； 最好在真实界面上点选控件让 clicktap 自己读。文本按「包含」匹配，目标 App 文案小变仍能命中。
    3. 屏幕位置（兜底）：坐标按屏幕百分比保存，换分辨率也能用；点「打开应用获取坐标」 在冻结画面上取点。它判断不了屏幕状态，只当兜底。
    4. 文字识别（Android 11+）：控件没有 ID 时（画布、网页、游戏），框选最多 三块区域搜屏幕文字，点击落在命中文字中心。
    5. 每个动作还有「执行前等待」超时：0 = 立即执行；大于 0 = 先等目标出现。这是扛住开屏广告的关键，下一部分有整段场景。

    完成标志：目标动作用了控件查找并配上等待，而不是裸坐标。

  5. 05

    循环与流程图

    这一步的目标：把重复的一段圈起来，让 App 自己转圈。

    1. 任务详情切到「流程图」视图。
    2. 长按一个动作，在菜单里「设为循环起点」，再选它后面的某个动作作为终点。
    3. 在弹窗里设重复次数和「定位失败时的后果」：中止整次回放，或丢掉本轮继续下一轮。循环支持嵌套，但循环是连续段，不能交叉。

    完成标志：流程图上循环区间出现「×N」徽标，回放按圈数执行。

  6. 06

    让它自己开始

    这一步的目标：不用你动手，任务到点自己跑。

    1. 任务详情 →「自动启动」。同一任务同一时刻只能启用一种触发，手动运行始终可用。
    2. 定时触发：选星期与时间点；再选回放起点——先回桌面（推荐）、先打开目标 App、停在当前界面。到点即使锁屏也会提醒（震动/响铃/自定义铃音），解锁后自动续跑。
    3. 消息触发：通知命中关键词就执行——下面的场景实战里有整段。
    4. 从 App 启动：指定 App 一进前台就执行。
    5. 定时要准点，前提是后台活着——先去做「常见坑」里的厂商后台设置。

    完成标志：设好触发并保存后，任务卡上出现触发条件，到点它自己运行。

场景实战

把学到的能力用在真实任务上

场景：第一百次跳过开屏广告

每次打开某 App 都要先看几秒广告、再小心点右上角「跳过」——让 clicktap 替你点。

前提

完成主线 01–02：能录制、能回放。

步骤

  1. 录制：打开那个 App，等广告出来，点一下「跳过」，结束录制并命名。
  2. 任务详情里点开「点跳过」那个动作，定位改成控件查找、文本填「跳过」；控件没有 ID 就用文字识别框住按钮区域。
  3. 给这个动作等待超时 8000 毫秒起步：等待是「最长找多久」，按钮一出现立刻点，广告短时也不干等。
  4. 「自动启动」里选「从 App 启动」并勾选这个 App——以后它一打开就自动跳广告。

为什么不用固定延时：广告时长每次不同，固定 5 秒往往广告过去了才醒来，点个空； 「等目标真的出现」才扛得住这种波动。

检查一下

完成标志：重新打开那个 App：广告按钮一出现就被点掉，全程没动手。

场景：导入一份回放脚本

回放脚本社区里每份内容 = 一个任务包 + 标题 + 说明。别人调好的任务，导入就能用。

前提

无需前提——刚装好的 clicktap 就能导入。

步骤

  1. 在手机浏览器打开回放脚本页，点「下载」——文件直接交给 clicktap，自动打开导入界面。也可以在文件管理器里点开 .clicktap 文件。
  2. 弹窗列出包里的任务，勾选要导入的。
  3. 与自己已有任务同名时，选「覆盖原任务」或「另存为副本」。
  4. 导入的任务，触发开关默认关闭——它不会自己跑起来。先读一遍它的动作，确认没问题再手动运行。

也支持导入 gkd 的 JSON5 订阅规则（URL 或文件），导入后常驻自动匹配，可按订阅单独启停。 自己的任务在详情页右上角导出 .clicktap：保存到本地、系统分享，或 GitHub 登录后 「分享到官网」。发布按原样存储、不做剥离——备注、匹配文本、关键词都会带上，发布页的清单请逐项确认。

检查一下

完成标志：导入的任务出现在列表里；它没有触发条件，不会自己跑。

场景：通知一到，自动就位

有些机会稍纵即逝：红包类的通知出现几秒就没了，限时券几分钟领完。消息触发让任务在通知到达的瞬间自己启动。

前提

在系统设置里开启「通知使用权」权限。

步骤

  1. 任务详情 →「自动启动」→「消息触发」。
  2. 选来源 App，填关键词：通知的标题或正文包含任一关键词即触发，可填多个。
  3. 勾选「先点开该通知」，让回放从正确的页面开始。

两个提醒

来源 App 关闭消息预览时，clicktap 只能读到占位文本（如「收到 1 条新消息」），关键词不会命中—— 请给那个 App 打开通知预览。另外，只自动化你有权自动化的操作，并遵守目标 App 的服务条款。

检查一下

完成标志：发一条含关键词的测试通知：任务不用你动手就自己启动了。

进阶与排障

出问题时的去处

出问题，先看执行日志

日志同时回答两个问题：这次为什么没执行（权限被关了？条件没到？），以及回放到哪一步失败。 记录按执行场次分组，长时间静默自动切段。打开「调试模式」，回放时叠加手势轨迹， 是看清「点到底落在哪」最快的方式。

任务突然失效时，几乎总是这几种，按顺序查：

  1. 目标 App 改界面了。在日志里找到失败的那一步，重新定位它。换版时控件 ID 比文本扛造。
  2. 屏幕不在你预期的位置。给失败动作的前一步加大等待，或把回放起点设为「先回桌面」。
  3. 系统更新关掉了权限。看首页「运行状态」。
  4. 出现了录制时没有的弹窗。把关掉它的那一下也录进去，用 ID 或文本定位。

常见坑：这些不是 bug

厂商后台杀进程

不少国产系统会在灭屏后很快冻结后台应用（前台服务也挡不住），表现为「定时到点没反应」。 设置 →「保活」里做三件事：开「忽略电池优化」；看「后台守护」状态（正常 / 需注意 / 有风险， 可「尝试拉起」）；照「厂商后台设置」的四步手动设置一遍——这一步只能你自己做：

  1. 最近任务界面：下拉 clicktap 卡片加锁；
  2. 手机管家 → 应用启动管理 → 关闭「自动管理」，打开「允许自启动 / 允许关联启动 / 允许后台活动」；
  3. 电池优化 → clicktap → 选「不允许」；
  4. 关闭省电模式。

无障碍服务被系统关闭

系统更新或省电策略可能悄悄关掉无障碍服务。守护通知会提醒「无障碍服务已被系统关闭」； 首页「运行状态」变红就是信号，点那行重新开启即可。

文字识别突然失效

提示「无障碍服务没有截图能力」时，去系统设置把 clicktap 的无障碍服务关闭再重新开启一次。 升级或重装 App 之后常见。

定时被系统推迟

未开启「闹钟和提醒」特殊权限时，定时可能被系统延迟。锁屏期间到点的任务不会立刻执行： 会发提醒通知，解锁后自动续跑。Android 14 及以上若要锁屏自动亮屏，还需「全屏通知（闹钟和提醒）」 权限；未授予时仍会响铃与震动。
